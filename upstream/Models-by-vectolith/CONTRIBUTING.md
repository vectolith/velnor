# Contributing

Keep all model-development work reproducible and reviewable. Never commit credentials, tokens, private user data, or datasets without documented rights.

For every foundation or teacher, record the exact model ID, immutable revision, license, model card, and evaluation evidence. Do not merge weights across incompatible architectures or tokenizers. Keep Prime and Prima objectives and evaluation suites distinct.

Dataset contributions must document provenance, license/permission basis, collection date, transformations, filtering, deduplication, privacy review, and intended splits. Teacher-generated data must record teacher revision, prompt/settings, validation, and human review where applicable.

Changes to foundations, training objectives, data policy, or promotion gates require rationale and evidence. Add tests and update documentation with every behavioural or pipeline change.
